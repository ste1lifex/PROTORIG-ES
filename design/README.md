# 表壳与底座设计

本目录提供适配 PROTORIG ES V1.6 的表壳和电脑模式底座模型。

| 目录 | 说明 |
|---|---|
| [A_with_back_cover/](A_with_back_cover/) | 内藏表带圆壳 V12，有底盖，宽台固定 PCB，底面两个卡针孔 |
| [B_monobody/](B_monobody/) | 内藏表带圆壳 V12，无底盖一体式，宽台固定 PCB，底面两个卡针孔 |
| [dock_pc_mode_v9_1/](dock_pc_mode_v9_1/) | 电脑模式底座 V9.1 |

STL 用于切片。STEP 可在 CAD 软件中查看或编辑，3MF 可导入支持该格式的切片软件。
`Assembly_*.step` 供检查装配关系，请用零件文件切片打印。打印前按材料和试装结果调整支撑和公差。
